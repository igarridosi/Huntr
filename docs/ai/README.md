# Instructions for AI coding agents

These files are prompts and context for the AI agents that help develop Huntr.
They are not project documentation; for that, start with the repository
README and `ARCHITECTURE.md`.

- `CONTEXT.md` (this folder) — the technical context an agent is given at the start of a session.
- [`.github/copilot-instructions.md`](../../.github/copilot-instructions.md) — read automatically by GitHub Copilot, so it stays where Copilot looks for it.

They are kept in the repository so a session can be reproduced, and so the
conventions they encode (design tokens, file layout, data-flow rules) stay next
to the code they describe.
